### what i'm working on

I run **Gatrion**, a tiny studio making utilities for people who build software. No accounts, no telemetry, no friction — just tools that live where you do.

- **[DevToolkit](https://kit.gatrion.my.id)** — 44 browser tools in one tab. JSON, hashing, images, QR, game-dev helpers. Everything runs client-side; nothing leaves your machine.
- **[DevLauncher](https://github.com/adi-santoso/gatrion_dev)** — a Windows desktop app that starts, stops, and watches every local project from one window. Laravel, Next.js, Vite, Go, Node — it detects the framework itself.
- **[Gatrion Docs](https://github.com/adi-santoso/gatrion-docs)** — a markdown-first documentation template built with Astro 7. Drop in a file, get a route, a sidebar entry, search results, and a table of contents. Ships with EN/ID locales.
- **[Gatrion Proxy](https://github.com/adi-santoso/gatrion-proxy)** — a Python proxy gateway with weighted rotation, circuit breakers, anonymous-only filtering, and a live dashboard.
- **[Temp Mail](https://github.com/adi-santoso/temp-mail)** — a Cloudflare Worker fork for disposable email. I added an admin panel and Mailjet replies on top of the original edge backend.

I like taking boring infrastructure problems and shipping something that feels nicer than it needs to be.
